# Elixia Parfum

Sitio web de catálogo de perfumes de Elixia Parfum. La página presenta fragancias, promociones y packs para clientes en Perú, con una experiencia optimizada para dispositivos móviles.

## Uso local

Abre ""index.html"" en un navegador o sirve la carpeta con cualquier servidor estático. Las imágenes del catálogo se encuentran en ""img/"".

## Configuración

Este proyecto estático no requiere variables de entorno ni dependencias de instalación.
